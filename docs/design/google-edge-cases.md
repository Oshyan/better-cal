# Google Calendar: Known Circumstances, by How Likely They Are

Written 2026-11-16 for [#243](https://github.com/Oshyan/better-cal/issues/243), against the code as of 1.5.8 (with 1.5.7's choice on a conflict for one event, on as shipped). It is for the owner to decide from before more Google code is written: what to handle, what to refuse and what to drop with a sentence. The promise itself, in plain words, is in [google-calendar.md](../google-calendar.md#what-better-cal-promises-and-what-it-doesnt).

Sources: every circumstance listed in #243, the known limits in the changelog for 1.5.5 to 1.5.8, and the open issues #254, #255, #266, #267, #269, #270, #272, #274, #276, #283 and #284.

**How to read it.** Rows are sorted most likely first. "How often" judges only how often the sequence occurs in normal use, never how bad the result is. "Today" is one of: handled; refused (with the sentence's gist); dropped and said; wrong, with an untrue sentence; or **silently wrong**. A row whose result is silently wrong is marked **Yes** in the last column. "Cheapest honest" is the least mechanism that would be honest: handle, refuse, or drop and say so. "Settled in" means the circumstance is answered by the code as of that version, and says how. "Unverified" means the row's "today" is read from an issue or a doc and was not checked against the code or a test for this page.

Words: "a change to all events" is a change for every day of a repeating event; "half done" is a change listed in Review as "Half done in Google Calendar"; "a stop" is a change that stopped part way (a lost connection, the server stopped, Google Calendar refused a later request).
