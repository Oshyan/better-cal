## What this changes

- A PATCH's start and end are merged into what Google holds, field by field: a start naming only the new form's fields leaves both a date and a clock there, which Google refuses as "Invalid start time." and writes nothing (3.18, 3.20, 3.22, 3.24, 3.26, 3.28, 3.30). Naming the old form's fields as null removes them, and every such body was taken (3.19, 3.21, 3.23, 3.25, 3.27, 3.29, 3.31). A change between timed and all-day must send those nulls, for a series, a single event and one day alike. Nothing here shows what a null does where the form does not change; the app sends none there.
- A zone change that moves no instant keeps every record (3.17), its own start reset to the pattern's as in 3.5, so the zone drops records only when the instants move (3.3).
- A link set on a series is written into every record, as a title is (3.32).
- A new rule keeps the records still on days of it and drops the rest (3.33, 3.34), as a bound change does.
- Two proven master changes in one body act as each alone (3.35).
